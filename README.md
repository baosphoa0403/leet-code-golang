# 📘 LeetCode Golang Roadmap

Structured Learning Path for Interview Preparation (FAANG-Level)

Repo này được thiết kế để luyện LeetCode bằng Golang theo **pattern-based learning** – học theo từng nhóm kỹ thuật (Two Pointer, Sliding Window, Binary Search, DP…). Mục tiêu: **nắm vững 70–100 bài cốt lõi**, đủ để đi phỏng vấn backend/go developer tại big-tech & product company.

---

# 🔥 1. Roadmap tổng quát (Study Path)

## **Stage 1 — Array & HashMap (Nền tảng)**

> Mục tiêu: làm quen pattern, xử lý tần suất, in-place array.

- Two Sum
- Valid Anagram
- Group Anagrams
- Longest Consecutive Sequence
- Top K Frequent Elements
- Missing Number
- First Missing Positive
- Contains Duplicate

---

## **Stage 2 — Two Pointers (Cơ bản → Nâng cao)**

> Pattern quan trọng nhất khi xử lý sorted array & string.

### **Basic**

- Reverse String
- Valid Palindrome
- Move Zeroes
- Two Sum II (sorted)

### **Medium / Must-do**

- 3Sum
- 4Sum
- Remove Element
- Remove Duplicates from Sorted Array
- Sorted Squares

### **Hard / Pattern Master**

- Container With Most Water
- Trapping Rain Water

---

## **Stage 3 — Sliding Window**

> Siêu quan trọng cho interview, nhất là vòng 1.

### **Core**

- Longest Substring Without Repeating Characters
- Minimum Window Substring
- Find All Anagrams
- Permutation in String

### **Advanced**

- Longest Repeating Character Replacement
- Sliding Window Maximum (Deque)

---

## **Stage 4 — Binary Search**

> Không biết binary search → fail 70% interview.

- Binary Search Basic
- Search Insert Position
- Find Minimum in Rotated Sorted Array
- Search in Rotated Sorted Array
- Koko Eating Bananas
- Median of Two Sorted Arrays (hard)

---

## **Stage 5 — Linked List**

> Ứng dụng fast–slow pointer & recursion.

- Reverse Linked List
- Merge Two Sorted Lists
- Linked List Cycle
- Remove Nth Node From End
- Reorder List (hard)

---

## **Stage 6 — Stack & Monotonic Stack**

> Quan trọng cho problem liên quan next greater, histogram.

- Valid Parentheses
- Min Stack
- Daily Temperatures
- Next Greater Element
- Largest Rectangle in Histogram (hard)
- Sum of Subarray Minimums

---

## **Stage 7 — DFS/BFS (Graph + Matrix)**

> Vòng phỏng vấn 2 rất hay hỏi.

- Number of Islands
- Max Area of Island
- Flood Fill
- Clone Graph
- Course Schedule (topo-sort)
- Pacific Atlantic Water Flow

---

## **Stage 8 — Dynamic Programming (DP)**

> DP là “final boss” của interview.

### **Basic**

- Climbing Stairs
- Fibonacci (top-down + bottom-up)

### **Medium**

- House Robber
- House Robber II
- Coin Change
- Longest Increasing Subsequence
- Partition Equal Subset Sum

### **Hard**

- Edit Distance
- Word Break
- Decode Ways
